# Web Scraping Project – Books Dataset

## Objective

The objective of this project is to collect and organize data from a public website using Python web scraping techniques. The extracted data is stored in a CSV file for further analysis and visualization.

## Tools & Technologies

* Python
* Requests
* BeautifulSoup
* Pandas
* Microsoft Excel

## Website Used

Books to Scrape (practice website for web scraping)

## Features

* Extracts book information from the website.
* Visits individual book pages to collect detailed information.
* Creates a structured dataset in CSV format.
* Stores multiple attributes for each book.

## Dataset Fields

1. Title
2. UPC
3. Product Type
4. Price (Excl Tax)
5. Price (Incl Tax)
6. Tax
7. Availability
8. Rating

## Output

The scraped data is exported to:

books_dataset.csv

## How to Run

Install required libraries:

pip install requests beautifulsoup4 pandas

Run the script:

python scraper.py
